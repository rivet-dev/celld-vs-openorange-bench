Full run timeline

Measured Azure Blob requests priced at S3 rates (GET/HEAD $0.0004, PUT/LIST $0.005 per 1,000, deletes free), projected to 730 hours. Not an AWS or Azure bill. Compute, egress and storage are excluded; stored-byte snapshots price at $0.0043/month or less.

Both platforms ran on the same Azure machines at each level (6 nodes at 8–1,024; 16 vCPU, 64 GB each). Rivet keeps 3 replicas of every write. Rivet Engine 3.0.0-preview.2, celld 0.6.3.
